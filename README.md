# the-snake
Игра 'Змейка'
(The game 'Snake').

Запуск (Launch): python the_snake.py
Зависимость (Dependency): pygame

Правила (Roles):
- Управляйте зеленой змейкой с помощью стрелок
(Control the green snake using the arrows).
- Собирайте красные яблоки и избегайте жёлтых груш, уменьшающих змейку
(Collect red apples and avoid yellow pears that make the snake smaller).
- Запрещён разворот на 180°
(Turning 180° is prohibited).
- При столкновении змейки с собой, игра стартует заново
(If the snake collides with itself, the game starts over).
